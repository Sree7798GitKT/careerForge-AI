# CareerForge AI 🚀

CareerForge AI is a full-stack MERN application that helps students prepare for placements by tracking coding progress, aptitude preparation, company applications, interview experiences, and resumes.

## Features

- User Authentication
- Company Application Tracker
- Coding Progress Tracker
- Aptitude Progress
- Interview Experience Manager
- Resume Upload
- AI Resume Review
- AI Interview Question Generator
- Interactive Dashboard

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
